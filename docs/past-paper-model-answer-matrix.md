# Past Paper Model Answer Matrix

## Purpose

This matrix tracks the past-paper model-answer files added to the `Dr-T-B/drama-tutor` GitHub repository for the Drama Tutor app / A-Level English Literature revision project.

It is designed as a project-control document, not a replacement for the full model-answer files. Its function is to show, at a glance, which Pearson Edexcel Component 1 Drama past-paper questions have full model answers, which files contain them, which Assessment Objectives apply, and whether each resource is safe for student/app use.

---

## Control Rules

- Exam board: Pearson Edexcel
- Qualification: A-Level English Literature
- Component: Component 1 — Drama
- Paper code: 9ET0/01
- Current matrix scope: Section A — Shakespeare — *Hamlet*
- Section A AO focus: AO1, AO2, AO3 and AO5 only
- AO4 comparison: not assessed in Section A Shakespeare
- Do not compare *Hamlet* with *The Duchess of Malfi* in Hamlet Section A model answers
- Target standard: high Level 5 / A-A*

---

## Status Key

| Status | Meaning |
|---|---|
| `CREATED` | File exists in the repository. |
| `MODEL_ANSWERS_COMPLETE` | File contains two full student-style model answers. |
| `AO_COMMENTARY_INCLUDED` | File contains examiner commentary by AO. |
| `REVISION_NOTES_INCLUDED` | File contains thesis guidance, quotations, AO5 routes and/or exam warnings. |
| `VERIFIED_FROM_PDF_OR_SOURCE` | Question wording is stated in the file as checked against the Pearson Edexcel past-paper source. |
| `NEEDS_REVIEW` | Use if a file is incomplete, missing, or not yet checked. |
